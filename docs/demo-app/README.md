# Onboard.qs demo apps

Two Qlik Sense apps that show what Onboard.qs can do, one sheet and one style of tour at a time:

| File                       | Language |
| -------------------------- | -------- |
| `Onboard.qs demo (EN).qvf` | English  |
| `Onboard.qs demo (SE).qvf` | Swedish  |

Both apps have the same four sheets and the same tours. They include their data, which the load
script generates, so there are no data connections to set up and nothing to reload.

To use them:

1. Install Onboard.qs 1.8.2 or later, as described in the README's
   [Getting Started](../../README.md#getting-started).
2. Import one or both files in the QMC (**Apps** › **Import**).
3. Open the app from the hub and go to sheet 1. The welcome tour starts by itself.

The [demo app tutorial](../DEMO-APP-TUTORIAL.md) walks through how every tour in the apps is built.
